In-place Array Reversal with Pointers

Type: Code Writing Topic: Arrays & Pointers Language: Python 3.10

Problem Description

Implement a function reverse_array(arr) that reverses a given list of integers in place using a two-pointer approach without utilizing built-in slicing or reverse methods.

Input Format
arr: List[int]
Output Format
None (Modify in place)
Constraints
  • 1 <= len(arr) <= 10^5
  • -10^9 <= arr[i] <= 10^9
  • Time Complexity: O(n), Space Complexity: O(1)

Expected Solution (Reference)

def reverse_array(arr: List[int]) -> None:
    left, right = 0, len(arr) - 1
    while left < right:
        arr[left], arr[right] = arr[right], arr[left]
        left += 1
        right -= 1
