State Architecture & Domain Separation

Clear boundaries separating server cache, global UI states, and ephemeral component state.

TQ

Server State (TanStack Query)

Handles all asynchronous API data fetching, caching, background refetching, and optimistic updates for problems, test results, and user submissions.

useQuery(['problem', id])
ZS

Global UI State (Zustand)

Manages cross-cutting UI toggles: active editor tabs, sidebar collapse states, terminal expansion, and active AI reasoning stream buffers.

useWorkspaceStore(state => state.activeTab)
HF

Form State (React Hook Form)

Handles complex instructor rubrics, prompt testing parameters, and student assessments with strict Zod schema validation.

useForm<RubricSchema>({ resolver: zodResolver(...) })

API & Service Boundary

Typed modular service clients wrapped around an enterprise Axios interceptor pipeline.

src/services/tutor.service.ts

Typed API Module
import { api } from './api.client';
import { TutorQueryDTO, TutorResponseDTO } from '../types/tutor.types';

export const tutorService = {
async askTutor(payload: TutorQueryDTO): Promise<TutorResponseDTO> {
const { data } = await api.post<TutorResponseDTO>('/v1/tutor/query', payload);
return data;
},
streamReasoning(sessionId: string, onChunk: (chunk: string) => void) {
return api.sse(`/v1/tutor/stream/${sessionId}`, onChunk);
}
};
