5. Security & Session Persistence Architecture

Under-the-hood implementation rules for token handling, page refreshes, and multi-tab synchronization.

JWT Refresh Interceptor (TypeScript) Axios Middleware 
apiClient.interceptors.response.use(
  (response) => response,
  async (error) => {
    const originalRequest = error.config;
    if (error.response?.status === 401 && !originalRequest._retry) {
      originalRequest._retry = true;
      try {
        const { token } = await refreshTokenRotation();
        setSecureToken(token);
        originalRequest.headers['Authorization'] = `Bearer ${token}`;
        return apiClient(originalRequest);
      } catch (refreshError) {
        purgeSessionAndRedirect('/login?expired=true');
        return Promise.reject(refreshError);
      }
    }
    return Promise.reject(error);
  }
);
Ensures seamless token rotation without interrupting active coding sessions or IDE test execution.

Multi-Tab Session Sync via BroadcastChannel

TRACE Tutor utilizes the browser BroadcastChannel API to synchronize authentication state across all open browser tabs instantly.

  • check_circle Logout Sync: Clicking logout in one tab immediately terminates sessions across all active tabs without requiring page reloads.
  • check_circle Role Update Propagation: Instant re-hydration of permissions when an instructor updates course enrollment tiers.
  • check_circle Secure Storage: Tokens are stored in HttpOnly cookies with CSRF protection headers; non-sensitive UI state resides in encrypted sessionStorage.
verified_user Zero localStorage token exposure to mitigate XSS vector severity.
