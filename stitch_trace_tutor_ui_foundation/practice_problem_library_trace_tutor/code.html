Reverse an Array

Topic: Arrays & Two-Pointer Manipulation

Learning Objective

Master memory swapping mechanics without allocating additional array buffers.

Problem Description

Given a zero-indexed array arr, write a function that reverses the order of its elements in-place. You must not use slicing or auxiliary arrays.

Constraints
  • 1 <= arr.length <= 10^5
  • -10^4 <= arr[i] <= 10^4
  • Time Complexity: O(N)
  • Space Complexity: O(1)
Example Test Cases
Input: [1, 2, 3, 4, 5]
Output: [5, 4, 3, 2, 1]
