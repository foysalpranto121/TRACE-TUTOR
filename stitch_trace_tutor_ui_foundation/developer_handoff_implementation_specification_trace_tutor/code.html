02 // Architecture

Core Component Library Mapping (React + Tailwind)

AppShell.tsx Layout

Master container enforcing fixed 260px sidebar and 64px header layout with content viewports.

Variants: Student, Expert, Admin
States: Expanded, Collapsed
CodeEditor.tsx IDE

Monaco-based multi-language code editor with syntax highlighting, linters, and live diagnostic markers.

Variants: Python, Java, C++, JS
States: Readonly, Editable, Error
TutorPanel.tsx AI Chat

Context-aware Socratic AI assistant drawer streaming code diagnostics and incremental hint guides.

Variants: Docked, Floating, Full
States: Idle, Streaming, Waiting
Console.tsx Output

Terminal output runner with color-coded stdout/stderr streams, stack trace collapse, and execution timing.

Variants: Tabbed, Split, Maximized
States: Running, Passed, Failed
ValidationRubric.tsx Assessment

Detailed assessment rubric card displaying test case pass rates, cyclomatic complexity, and style adherence.

Variants: Compact, Expanded
States: Pending, Verified, Flagged
ResearchMetricCard.tsx Analytics

Telemetry analytics card displaying live participant interaction metrics, RAG retrieval scores, and P-values.

Variants: Sparkline, Bar, Ring
States: Live, Cached, Stale

06 // Compliance

Accessibility & Responsive Standards

verified_user

WCAG 2.2 AA Compliance

All text elements meet or exceed 7:1 contrast ratios against dark charcoal backgrounds. Focus rings use explicit cyan outlines (`outline: 2px solid #4cd7f6`). Minimum touch targets are strictly maintained at 44x44px.

devices
