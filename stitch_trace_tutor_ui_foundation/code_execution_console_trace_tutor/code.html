Problem Brief info

Given an array of integers nums, find the maximum element and return its index using an optimized linear scan.

Example 1:

Input: nums = [3, 2, 5, 1, 4]

Output: 2

Explanation: Maximum value is 5 at index 2.

Constraints:
  • 1 ≤ nums.length ≤ 10&sup5
  • -10&sup4 ≤ nums[i] ≤ 10&sup4

class Solution:
    def findMaximumIndex(self, nums: List[int]) -> int:
        # Edge case handling
        if not nums:
            return -1
        
        max_val = nums[0]
        max_idx = 0
        
        for i in range(1, len(nums)):
            if nums[i] > max_val:
                max_val = nums[i]
                max_idx = i
                
        return max_idx
