description Problem Description

Given an array of integers, write an efficient linear scan algorithm to find the absolute maximum value without using built-in max functions. Return the integer value representing the peak element in O(N) time complexity.

school Learning Objective

Master single-pass array traversal, conditional comparisons, and boundary condition handling in C++ and Python without incurring auxiliary space overhead.

Requirements & Specifications

  1. Linear Scan: Iterate through the array exactly once (O(N) time).
  2. State Tracker: Maintain a running maximum tracker initialized to the first array element or minimum sentinel.
  3. Edge Cases: Handle single-element arrays and negative integer bounds gracefully.
INPUT FORMAT

An integer array arr of size n where 1 <= n <= 10^5.

OUTPUT FORMAT

A single integer representing the maximum value found in the array.

COMPLEXITY CONSTRAINTS
bolt Time: O(N)
memory Space: O(1)
