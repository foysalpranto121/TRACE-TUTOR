When implementing a linear scan over an array or list of size $n$, failing to account for $n=0$ leads directly to an IndexError or unhandled memory dereference when attempting to evaluate the initial element arr[0].

According to NCTB ICT Chapter 5.4 on algorithmic safety, sequential search architectures must evaluate structural cardinality prior to iteration binding.

python • linear_scan_safe.py 
def secure_linear_search(arr, target):
    # Guard clause against empty array allocation (n=0)
    if not arr or len(arr) == 0:
        return -1
        
    for index, value in enumerate(arr):
        if value == target:
            return index
    return -1

By enforcing this boundary check, your runtime environment prevents out-of-bounds execution faults, ensuring O(n) algorithmic resilience.
