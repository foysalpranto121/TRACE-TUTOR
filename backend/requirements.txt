# Exact versions, deliberately.
#
# This platform is the instrument for a controlled experiment: a run has to be
# reproducible months later, and a silent minor-version bump in the model client or the
# vector store is a confound nobody would think to look for. Bump these on purpose,
# re-run `python manage.py test`, and note the change in the study log.
#
# Verified against Python 3.11-3.13.
