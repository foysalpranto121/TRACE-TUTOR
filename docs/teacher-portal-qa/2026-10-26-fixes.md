# Expert portal QA fixes — 26 October 2026

Implemented against the supplied browser QA report and deployed to https://trace.musfiqurtuhin.me/expert on 26 October 2026 at 18:34 Asia/Dhaka.

- Grade drafts are keyed by submission ID and scoped to the authenticated account in memory. Switching submissions or tabs and refreshing the submissions list preserves marks, feedback, and the original grade revision. Failed saves retain drafts; successful saves remove only that submission's draft. Explicit conflict recovery loads the latest server grade and discards the selected draft. Drafts trigger a browser refresh/close warning and show a visible save-before-leaving notice. They are not persisted to browser storage.
- The narrow-screen navigation uses the browser's native modal dialog API, which supplies focus containment and background inertness. Opening focuses a named close button. Native Escape cancellation, the close button, backdrop clicks, route changes, and desktop resizing dismiss the drawer. Closing restores focus to its opener.
- Expert UI copy follows AuthContext's selected language through a dedicated Bengali/English message table. This covers headings, tabs, navigation, criteria, field labels, placeholders, actions, statuses, errors, draft notices, and timing labels. Authored assessment content remains unchanged and Bengali content receives language metadata.
- Both logout buttons have localized accessible names at every viewport width.
